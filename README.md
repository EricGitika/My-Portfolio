# Eric Gitika — Portfolio Website

A simple, responsive personal portfolio website built with HTML and CSS. It introduces me, showcases my skills and interests, highlights a featured project, and provides ways to get in touch.

##  Live Demo

Check out the featured project here: [Habitat Studio](https://ericgitika.github.io/Final-Project/)

##  About

This portfolio is a single-page website with smooth navigation to different sections, giving visitors a quick overview of who I am, what I do, and how to reach me.

##  Features

- **Hero Section** — A profile photo and short bio introduction
- **About Me** — Background, skills, and interests
- **Projects** — A showcase of my work, including live links
- **Contact** — Links to GitHub and email for easy outreach
- **Responsive Styling** — Clean layout with hover effects and a cohesive color palette

##  Built With

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and hover animations
